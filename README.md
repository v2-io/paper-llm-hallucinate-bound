# How Much Can LLMs Hallucinate? An Upper Bound on Goal-Coupling Displacement — paper repository

*An upper bound on goal-coupling-induced displacement of an LLM's post-update belief state.* Single-author theory paper. Umbrella theorem $\mathbb{E}\,\|\Delta M_{\text{bias}}\| \leq C\sqrt{I(G; M_{\tau^+} \mid e_\tau, M_{\tau^-})}$ on transferred goal-information, with $C$ supplied by two tracks: transport-inequality (Talagrand $T_2$; Otto–Villani + Stuart-school posterior stability) and Fisher–Rao geometry (Čencov uniqueness under (PI) parameterization-invariance — $C = 2$ globally on the ambient spherical arc, tightening to $\sqrt 2$ locally under (R)+(K)+(H4$'$)). A no-go theorem rules out universal Euclidean-chart-norm constants, making the (PI) commitment load-bearing. Under (H$_\kappa$) the bound factors as coupling strength × residual ambiguity, $C\sqrt{\kappa^\ast \cdot I(G; \Omega_\tau \mid e_\tau, M_{\tau^-})}$; the Class 1/2/3 (Separated / Partial / Coupled) ladder operationalizes $\kappa_{\text{processing}}$, with transformer attention Coupled by construction.
